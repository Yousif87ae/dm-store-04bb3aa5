- `updates.json` — بيان المُحدِّث داخل تطبيقَي أندرويد/الماك.
- `open-source-store.json` — مصدر AltStore/SideStore لآيفون.
- الحزم (APK · DMG · IPA) في **Releases**.

Private distribution for "Download Manager". Manifests + binaries only (source code lives in a private repo).
